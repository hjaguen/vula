## Instalación Rápida

Para instalar Vula en una copia limpia de Ubuntu 24.04 LTS Noble:

```bash
wget -qO- https://raw.githubusercontent.com/hjaguen/vula/main/scripts/install.sh | bash
```

Una vez instalado, abre el **HUD flotante** con:

```text
Super + Space
```
