# 19 Temas Curados & Fondos HD

Vula incluye un motor de temas estéticos que sincroniza la paleta de colores de todo tu sistema en un solo comando: terminales (`Ghostty`, `Alacritty`), multiplexor (`Tmux`), editor (`Neovim`), resaltado de bordes de ventanas de GNOME y modo claro/oscuro.

## 🛠️ Comandos de Temas

```bash
# Aplicar un tema
vula theme set tokyonight

# Listar todos los temas instalados
vula theme list

# Diseñar un tema interactivo con Vula Studio TUI
vula theme create

# Generar un tema personalizado con IA
vula theme generate "estética retro cyberpunk neón verde"

# Ver vista previa de colores en terminal
vula theme preview tokyonight
```

---

## 🖼️ Gestión de Fondos de Pantalla (`vula wallpaper`)

```bash
# Cambiar al siguiente fondo de la colección
vula wallpaper next

# Establecer un fondo específico
vula wallpaper set mi-fondo.png

# Descargar la colección completa de fondos HD
vula wallpaper fetch

# Listar fondos almacenados en ~/.config/vula/wallpapers
vula wallpaper list
```
